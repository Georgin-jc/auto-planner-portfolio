03 / THE SYSTEM

Behind the project

Other capabilities in brief.

Data preparation

CSV/GeoPackage integration, data filtering, coordinate updates and address-to-road snapping.

Territory creation

Voronoi-based planning, road-connected clustering and district balancing.

Network modeling

Vehicle-specific graphs, directional restrictions, barriers and configurable road access.

Route optimization

Network-distance ordering with nearest-neighbor and local optimization, plus route exports.

Built with Python · PyQGIS · GeoPandas · Shapely · SciPy · Pandas · road-graph algorithms
