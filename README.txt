Auto Planner — compact portfolio website

Open index.html in any modern browser. No server, installation or external libraries needed.

Contents:
 index.html          Portfolio page
 styles.css          Responsive layout
 script.js           Screenshot enlargement
 assets/             Three user-provided screenshots and one compressed route-demo MP4

To publish: upload the complete directory and keep assets/ at the same relative path.
The supplied MP4 was reduced to 1280px wide with H.264 to make the portfolio smaller; the duration and content are preserved.

This is a standalone portfolio page, not a change to the Auto Planner QGIS plugin.
